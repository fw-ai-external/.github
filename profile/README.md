## What do you want to build?

| Your goal | Start here |
| :--- | :--- |
| **Build an application** | [Python SDK](https://github.com/fw-ai-external/python-sdk): call models, stream responses, and work with the Fireworks API. |
| **Connect your coding tools** | [Nexus CLI](https://github.com/fw-ai-external/nexus-cli): use Fireworks in Claude Code, Codex, Cursor, and other coding tools. |
| **Train a model for your task** | [Training cookbook](https://github.com/fw-ai-external/cookbook): runnable recipes for fine-tuning, reinforcement learning, and distillation. |
| **Measure inference performance** | [Benchmark suite](https://github.com/fw-ai-external/benchmark): measure latency, throughput, and streaming performance. |

**Training from your coding agent?** Add [training skills](https://github.com/fw-ai-external/cookbook#for-ai-agents) to help choose a method, plan a run, and debug jobs. Explore the [Training API docs](https://docs.fireworks.ai/fine-tuning/training-api/introduction) for more detail.

**More tools:** use [firectl](https://docs.fireworks.ai/tools-sdks/firectl/firectl) to manage deployments, models, datasets, and training jobs from your terminal. See the [Nexus docs](https://docs.fireworks.ai/nexus) for coding-tool setup.

## Learn by building

Follow a guided workshop from setup to a working result. Each workshop includes its own requirements and instructions.

- **[Train a research agent](https://github.com/fw-ai-external/forge-workshops/tree/main/research-agent-rl)**: use reinforcement learning for multi-hop research, then run the model as an agent.
- **[Train a model router](https://github.com/fw-ai-external/forge-workshops/tree/main/decision-router)**: train a decision model to route between models.
- **[Turn a skill into model weights](https://github.com/fw-ai-external/forge-workshops/tree/main/skill-to-weights)**: use supervised fine-tuning and a Python scoring function.

[Browse all workshops →](https://github.com/fw-ai-external/forge-workshops)

## Explore the engineering

Read [MiniMax kernels](https://github.com/fw-ai-external/minimax-kernels): open-source GPU kernels for MiniMax models, including MiniMax M3 sparse attention on NVIDIA Blackwell. The [design and performance write-up](https://fireworks.ai/research/minimax-m3-sparse-attention-kernel-blackwell) explains how they work.

## Get help

- **Questions, ideas, or something to share:** join the [Fireworks Community](https://forum.fireworks.ai/) to discuss what you are building and learn from other developers.
- **API and setup reference:** visit the [documentation](https://docs.fireworks.ai/).
- **Repository bugs or feature requests:** open an issue in the relevant repository. For bugs, include the steps to reproduce them.
- **Account, billing, or private troubleshooting:** contact [Fireworks support](mailto:support@fireworks.ai).
- **Want to contribute:** follow the contribution guidance in the repository you want to improve.
